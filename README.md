# Amama Ali Portfolio

Frontend-only single-page portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## What is included
- Cream/light locked aesthetic
- Responsive one-page layout
- Fixed navbar with mobile fullscreen menu
- Hero with custom cursor and animated portrait ring
- About, Education, Experience, Projects, Skills, Certifications, Contact, Footer
- Frontend-only mailto contact form
- CV download area
- Vercel-friendly structure

## Replace placeholders
- Put the CV PDF at: `public/cv/amama-cv.pdf`
- Replace the profile image at: `public/images/profile-placeholder.svg` or swap the `src` in `src/components/Hero.jsx`

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
